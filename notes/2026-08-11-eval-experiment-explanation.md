## 第七段：這個專案做了什麼實驗、量到什麼數字

工程師常說「沒有量測過的東西，不能說它更好」——這個專案很在意這件事，特別做了一個**對照實驗（control experiment）**來證明「規則層 + AI」真的比「純 AI」好，而不是憑感覺說說而已。

### 先講怎麼「造」出測試資料

真實企業的發票不能拿來用（隱私+版權問題），所以專案裡寫了一支 `data/generate_synthetic.py`，**自己生成 50 份假發票/報關單**當測試集，特意做得「刁鑽」：
- 中英德混合語言
- 有的是乾淨的電子 PDF（有文字層，能直接讀文字）
- 有 10 份是「噪點掃描件」——故意轉成圖片再壓 JPEG，模擬真實世界掃描品質差的情況，**這種文件完全沒有文字層可讀，只能靠 AI 看圖辨識**
- 有 7 份「故意拿掉某個欄位」，測系統會不會硬掰一個答案出來

同時產生一份 `ground_truth.json`（正確答案），這樣才能拿系統抓出來的結果去對答案、算準確率。

### 對照實驗怎麼做

還記得上一段提到 `pipeline.py` 裡有個開關 `rules_enabled=False` 嗎？就是靠它做這個實驗——**兩組跑一模一樣的程式碼、一模一樣的 50 份文件，唯一差別是要不要開啟規則層**：

```bash
# 組別 A：規則層 + AI（deterministic-first，這個專案主打的做法）
python eval/evaluate.py --api http://localhost:8000

# 組別 B：純 AI（RULE_LAYER_ENABLED=0，關掉規則層，每個欄位都問 AI）
docker compose run ... -e RULE_LAYER_ENABLED=0 ... api
python eval/evaluate.py --api http://localhost:8001
```

### 實測結果

| 指標                       | 規則層+AI（本專案做法）        | 純 AI（對照組） |
| -------------------------- | ------------------------------ | --------------- |
| 欄位級準確率               | 99.7%（334 個欄位中對 333 個） | 99.7%（一樣）   |
| 自動通過的文件，正確率     | **100%**（43 份全對）          | 100%（一樣）    |
| 需要人工介入的比例         | 14%                            | 14%（一樣）     |
| 由規則層免費抓到的欄位比例 | **79.5%**                      | 0%              |
| 每份文件平均花費           | **$0.00195**                   | $0.00589        |
| 處理速度（中位數）         | **65 毫秒**                    | 3768 毫秒       |

**怎麼解讀這張表：** 準確率兩組一樣（因為 79.5% 用規則抓的欄位本來就有數學驗證撐腰，跟 AI 判斷的準確度打平），但**成本省了 67%、速度快了 58 倍**——因為將近 8 成的欄位根本沒有勞煩 AI 出馬。**規則層不是「犧牲準確率換速度」，而是「同樣準確率下，把不需要 AI 的工作交給便宜又快的規則去做」**，把 AI 這個較貴的資源留給真的需要「看圖判斷」的困難案例（比如那 10 份噪點掃描件）。

### 最有意思的一個發現：AI 會「一本正經地編答案」

50 份文件裡，兩組實驗都各錯了同一個欄位——`invoice_048.pdf` 這份文件，測試資料裡故意把「總金額」這一行整個刪掉。結果 GPT-4o Vision **自己編了一個總金額 `4720.55`**，講得煞有其事——但文件上根本沒有這個數字，這叫「幻覺」（hallucination）：AI 有時候會很有自信地講出一個編造的答案，而不是老實說「我不知道」。

**但這裡才是這個系統設計真正的價值所在：** 雖然 AI 編了假的總金額，但同一份文件的「幣別」欄位也被一起刪掉了，AI 抓不到幣別——**幣別這個欄位缺失，就把整份文件拖到 human_review**，那個編造的金額根本沒有機會被寫進資料庫。

這正好呼應第一段講的核心理念：**擋住「一本正經編答案」的防線，靠的不是把 prompt 寫得更好去「說服」AI 不要亂猜，而是架構層面「只要有任何一個欄位有缺口，就不准自動放行」這條硬規則**。就算 AI 對其中一個欄位很有自信地講錯，只要系統整體上還有別的破綻沒補齊，人就會被叫進來把關。這是「supervised autonomy」這個理念真正落地的地方。
